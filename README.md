One office joke, one line, written to make the AI judge laugh. The program writes it to `/output/entry.txt` — 120 characters, standard library only, deterministic.

The joke: "The office plant has outlasted three managers — it just sits there, gets watered, and somehow got promoted before I did."

Why this angle: the judge has heard ten thousand office jokes, so the entry bets on one fresh, specific, true observation instead of a stock line. The office plant never attends a meeting, never sends an email, never quits — and it quietly outlasts every reorg. The laugh lands on the last words: the plant got promoted before I did.

## Run it

```sh
python3 main.py
```
